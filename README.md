# PetHeaven

Helyi Állatmenhely Örökbefogadó és Támogató Rendszer
A lényeg: Egy webes katalógus a menhelyen lévő állatokról (kutya, macska), részletes adatlappal, szűrési feltételekkel (kor, méret, fajta). A felhasználók "támogathatják" virtuálisan az állatokat, vagy örökbefogadási kérelmet küldhetnek be.
